# Internet

[REVENIR AU SOMMAIRE](README.md)

Internet est un **réseau mondial de réseaux interconnectés**.

Ce n'est pas un unique réseau appartenant à une seule organisation.

On peut le représenter ainsi :

```text
Réseau A
   │
   │
   ▼
Réseau B
   │
   ├────────── Réseau C
   │
   └────────── Réseau D
                  │
                  ▼
               Réseau E
```

Internet utilise une suite de protocoles permettant à ces réseaux de communiquer.

Exemples :

```text
IP
TCP
UDP
DNS
HTTP
TLS
BGP
...
```
