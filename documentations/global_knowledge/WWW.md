# WWW

[REVENIR AU SOMMAIRE](README.md)

**WWW** signifie :

```text
World Wide Web
```

Le Web est une application fonctionnant sur Internet.

Il permet notamment d'accéder à des ressources via des URL.

Exemple :

```text
https://example.com/page
```

Le Web utilise principalement :

```text
HTTP / HTTPS
```

Le navigateur communique avec un serveur web.

```text
Navigateur
     │
     │ HTTP / HTTPS
     ▼
Serveur Web
     │
     ▼
Ressource
```

### Internet ≠ Web

Internet est l'infrastructure et l'ensemble de réseaux.

Le Web est une application qui utilise Internet.

D'autres applications utilisent également Internet :

```text
Email
IRC
DNS
VoIP
FTP
Jeux en ligne
...
```
