# DCC (Direct Client-to-Client)

[REVENIR AU SOMMAIRE](README.md)

**DCC** signifie :

```text
Direct Client-to-Client
```

DCC est un mécanisme historiquement utilisé avec IRC pour permettre à deux clients d'établir une communication directe.

Normalement :

```text
Client A
    │
    ▼
Serveur IRC
    │
    ▼
Client B
```

Avec DCC :

```text
Client A
    │
    │ connexion directe
    ▼
Client B
```

Le serveur IRC sert généralement à négocier ou annoncer les informations nécessaires à l'établissement de la connexion.

DCC peut être utilisé pour :

* transfert de fichiers ;
* conversation directe ;
* autres échanges directs.
