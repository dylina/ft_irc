# IP

[REVENIR AU SOMMAIRE](README.md)

**IP** signifie :

```text
Internet Protocol
```

IP est le protocole permettant notamment l'adressage et l'acheminement des paquets entre réseaux.

IP fonctionne à la **couche réseau (couche 3 du modèle OSI)**.

Les deux versions principales sont :

```text
IPv4
IPv6
```

## IPv4

Une adresse IPv4 possède :

```text
32 bits
```

Exemple :

```text
192.168.1.10
```

## IPv6

Une adresse IPv6 possède :

```text
128 bits
```

Exemple :

```text
2001:db8::1
```

IP fournit principalement un système permettant d'identifier les destinations et d'acheminer les paquets.

Il ne garantit pas à lui seul :

* la livraison ;
* l'ordre ;
* la retransmission.

C'est notamment le rôle de protocoles de transport comme TCP de fournir certaines garanties supplémentaires.
