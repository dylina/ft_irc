# SYN

[REVENIR AU SOMMAIRE](README.md)

**SYN** signifie :

```text
Synchronize
```

C'est un flag TCP.

Il est utilisé lors de l'établissement d'une connexion TCP.

```text
Client
  │
  │ SYN
  ▼
Serveur
```

Le SYN permet notamment d'initialiser les numéros de séquence nécessaires à la communication TCP.
