# RFC

[REVENIR AU SOMMAIRE](README.md)

**RFC** signifie :

```text
Request For Comments
```

Une RFC est un document technique publié dans le cadre du processus de standardisation d'Internet.

Les RFC peuvent définir :

* des protocoles ;
* des formats ;
* des standards ;
* des bonnes pratiques ;
* des informations techniques ;
* des extensions.

L'IETF publie de nombreuses RFC importantes.

Exemples :

```text
RFC 791   → IPv4
RFC 9293  → TCP
RFC 768   → UDP
RFC 5321  → SMTP
```

Une RFC publiée possède un numéro unique.

Une RFC n'est pas forcément un standard obligatoire : certaines sont informatives, expérimentales, historiques, etc.
